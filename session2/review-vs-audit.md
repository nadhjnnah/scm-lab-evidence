\# Review vs Audit



A code review is a peer check of a proposed change to improve code quality. In my project, I reviewed Pull Request #2, which added a traceability note template, and provided feedback through a review comment.



A formal configuration audit is a planned and independent verification. A Functional Configuration Audit (FCA) checks whether the product meets its requirements, while a Physical Configuration Audit (PCA) checks whether the product and its documentation match.
